# V1 Scope

## Purpose of V1
The purpose of V1 is to prove that Primer can deliver a uniquely compelling, premium learning experience with strong retention and meaningful personalization.

V1 is not intended to solve every use case. It is intended to validate the core product loop.

## Primary Goal
Build the smallest impressive version of Primer that demonstrates:
- story-based learning
- persistent learner memory
- adaptation over time
- a premium user experience
- a clear reason to come back repeatedly

## V1 Target User
Adult learner using Primer for language learning.

Initial target profile:
- motivated self-directed learner
- interested in Spanish and/or Chinese
- wants learning to feel more personal and engaging than Duolingo or generic chatbots
- values depth, continuity, and explanation
- willing to pay for a premium experience

This user includes the founder as a core dogfooding user.

## Initial Subject Focus
Language learning only.

Initial languages:
- Spanish
- Chinese

V1 should support one language well first if needed before expanding to both.

## V1 Core Promise
Primer helps a learner improve language ability through personalized, story-based, adaptive sessions that remember the learner and build over time.

## Core V1 Product Loop
1. User starts or resumes a session
2. Primer continues a narrative or guided learning interaction
3. User practices through reading, response, comprehension, explanation, and guided dialogue
4. Primer adapts difficulty and explanation style
5. The system saves structured memory from the session
6. The next session reflects prior learning, interests, gaps, and story continuity

## Included in V1

### 1. Authentication
- account creation and login
- one primary learner profile per account

### 2. Learner Profile
The system stores:
- target language
- current level or self-estimated level
- goals
- interests
- preferred style or pacing if available

### 3. Story-Based Learning Session
A learner can:
- begin a guided session
- continue from a prior session
- interact with a story-based or scenario-based learning experience
- receive explanations, corrections, and prompts

### 4. Structured Memory
The system saves useful information after sessions, such as:
- vocabulary gaps
- recurring mistakes
- confidence indicators
- recent themes
- interests revealed in conversation
- story state or continuity markers

### 5. Basic Learner Progress View
A simple premium dashboard that shows:
- current learning streak or recent activity
- active language
- recent themes or story arcs
- vocabulary or skill focus areas
- suggested next session

### 6. Session History
The learner can see recent sessions and resume progression.

### 7. Premium UI Foundation
The app should feel polished, warm, elegant, and intentionally designed.
It should avoid a generic AI chatbot aesthetic.

## Explicitly Not in V1

### Not included yet
- homeschool parent dashboard
- multiple child profiles
- ESA purchase workflows
- state approval workflows
- curriculum mapping across many subjects
- full voice mode
- video generation
- broad subject support outside language learning
- deep gamification systems
- marketplace/community features
- teacher/school admin tools
- detailed formal assessments
- advanced scheduling or cohort features

## Nice-to-Have but Optional in V1
These may be included only if they do not slow down the core loop:
- image generation for scenes or vocabulary support
- external resource suggestions
- onboarding quiz or placement flow
- simple spaced review suggestions

## V1 UX Principles
- warm, premium, narrative-first
- low clutter
- not dashboard-heavy
- not chatgpt-clone styling
- every visible feature should support learning and continuity

## What Must Be Proven in V1
V1 should answer these questions:
1. Do users find story-based learning meaningfully more engaging?
2. Does structured memory make the product feel personalized over time?
3. Does the user feel a desire to return for the next session?
4. Can the system maintain useful continuity without becoming messy or confusing?
5. Can this experience justify premium pricing?

## Success Metrics for V1
Success is not just usage volume. Key indicators include:
- repeat usage across multiple days
- session completion rate
- return rate after first session
- subjective feeling of personalization
- perceived learning value
- willingness to continue paying for the experience

## V1 Strategic Role
V1 is a focused proving ground for the core interaction model.

If successful, V1 can later expand toward:
- child learner mode
- homeschool family features
- broader subjects
- ESA-aligned educational positioning
