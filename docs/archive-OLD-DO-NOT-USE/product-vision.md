# Product Vision

## Working Title
Primer

## Inspiration
This product is inspired by *The Young Lady's Primer* from Neal Stephenson's *The Diamond Age*.

The goal is not to literally recreate the book, but to build a modern learning companion that feels personal, intelligent, memorable, and deeply engaging. It should teach through story, dialogue, curiosity, images/short-AI-generated videos, adaptive guidance, and emotional continuity rather than just presenting static lessons or generic chatbot responses.

## Core Idea
Primer is an interactive learning companion that helps users learn languages and other subjects through personalized, story-driven, adaptive experiences.

It should:
- teach through stories, examples, conversation, and guided discovery
- remember the user over time in a meaningful way
- build a model of the user's interests, goals, strengths, weaknesses, and learning history
- adapt difficulty, style, pacing, and explanations
- use images and external resources when they genuinely improve understanding
- feel more like a mentor, guide, and narrative learning environment than a standard AI chat interface
- eventually search the web to present 3rd party links to YouTube videos/resources/courses
- leverage other internal agentic tools that are plugged into the core AI interaction

## Long-Term Vision
In the long run, Primer should become a premium, official-feeling educational platform that can serve:
- adult learners, especially for language learning and professional development
- homeschooling families (prioritizing K-8 at first)
- children learning core subjects, curiosity, values, and habits of thinking

The platform should eventually be credible enough to be positioned as:
- a premium learning companion
- a personalized tutoring and curriculum support system
- an Education Savings Account-aligned educational product for homeschool families

## Initial Strategic Direction
The long-term market opportunity includes homeschooling families and ESA-funded educational spending, especially in states where parents can use public education funds on approved educational products (Florida, Arizona, Utah, and West Virginia).

However, the best initial product direction is to begin with a narrower wedge that proves product quality, retention, and learning value before expanding broadly.

The likely initial wedge is:
- story-based language learning
- highly personalized
- premium user experience
- strong memory and continuity across sessions

This initial wedge is especially attractive because it aligns with the founder's personal goals and creates a realistic path to daily dogfooding.

## Product Principles

### 1. Learning should feel alive
The experience should feel dynamic, warm, intelligent, and emotionally continuous. It should not feel like a worksheet engine or a generic chatbot.

### 2. Story is a teaching tool, not decoration
Narrative should be used to improve engagement, memory, context, and curiosity. Stories should help learners remember concepts, vocabulary, and ideas.

### 3. Memory should be structured, not just saved chat history
The system should remember useful facts about the learner, including:
- goals
- interests
- preferred tone and pacing
- prior lessons
- recurring mistakes
- confidence level
- vocabulary gaps
- mastery progression
- meaningful story continuity

### 4. The system should model the learner
Primer should not simply answer prompts. It should build an evolving understanding of what the learner knows, struggles with, cares about, and should encounter next.

### 5. Premium trust matters
The product should feel polished, intentional, safe, and credible enough for serious learning use. This matters especially if the product is later positioned for homeschool and ESA-funded use.

### 6. Multimodality should be purposeful
Images, diagrams, and possibly audio or video should be used when they meaningfully improve learning, not just because they are possible.

### 7. Avoid generic AI product patterns
The product should avoid:
- generic chat app layouts
- shallow memory claims
- gimmicky AI interactions
- feature bloat without pedagogical value
- bland dashboard design that feels auto-generated

## Differentiators
Primer should eventually stand out on these dimensions:
1. Story-based, adaptive pedagogy
2. Strong structured learner memory
3. Personalized continuity across sessions
4. Premium, non-generic product and interface design
5. Broad applicability across languages and other subjects over time through building comprehensive learning plans with structure, including assessments to measure and celebrate progress

## Initial User Types Considered
Potential user groups include:
- adult language learners
- homeschooling parents
- homeschooled children
- curious children learning across subjects
- parents seeking a premium educational companion for their child

## Most Likely First User
The most realistic starting point is an adult learner using Primer for language learning, especially Spanish and Chinese.

Reasons:
- strong founder-product fit
- daily dogfooding opportunity
- lower safety and compliance complexity than child-first design
- faster product iteration
- can later inform expansion into homeschool use

## Future Expansion Paths
If the core product works, future expansion may include:
- child learner profiles
- parent dashboards
- homeschool curriculum support
- ESA/vendor alignment
- subject-specific learning tracks
- audio-first and voice-based learning
- classroom or microschool versions

## Success Criteria for the Product Vision
A successful version of Primer should make users feel:
- understood
- motivated to return
- emotionally connected to learning
- better able to retain information
- more curious and confident over time

The product should eventually be good enough that users describe it not as "an AI tutor" but as "my guide" or "my child's learning companion."
